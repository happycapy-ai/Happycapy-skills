# gbro-collage-broll

A Claude Code skill that turns a voiceover script into a premium editorial **halftone paper-collage assemble-from-empty B-roll** — from a single ~5 second hook clip up to a fully-segmented, narrated brand ad.

Adapted for the Happycapy AI Gateway environment from [pyang5166/gbro-collage-broll](https://github.com/pyang5166/gbro-collage-broll) (MIT license, original author retained in `LICENSE`). The original targets a Codex environment with a direct `GEMINI_API_KEY`; this version replaces both dependencies with the AI Gateway so it runs out of the box wherever `AI_GATEWAY_API_KEY` is already configured.

## What changed from upstream

- **No Codex, no direct Google API key.** Gate 2 still frames are generated with the bundled `scripts/generate_still_gateway.py` (AI Gateway `images/generations`, model `openai/gpt-image-2` for the empty first-frame plate, `google/gemini-3.1-flash-image` for content frames) instead of Codex's built-in `image_gen`. Gate 3 video calls the sibling `generate-video` skill's `generate_video_sdk.js` (AI Gateway → `google/gemini-omni-flash-preview`) instead of a direct `google-genai` SDK call.
- **New Gate 0 — segmentation and duration planning.** Long scripts get auto-split into segments; `scripts/estimate_duration.py` computes each segment's duration from actual voiceover length (≈4 chars/sec for Chinese, ≈2.3 words/sec for English, +1.5s buffer, clamped to Gemini Omni Flash's 5–10s window) instead of a fixed 5 seconds. Background color defaults to one unified color across a whole batch (brand consistency) instead of a different color per segment.
- **Gate 0 also asks the user up front** whether they want burned-in captions and whether a real brand logo must appear — both are handled as post-production ffmpeg passes (`drawtext` for captions, a real logo file composited on a dedicated end card), never generated by the image/video model itself.
- **Optional native-audio branch.** Gemini Omni Flash can generate synchronized voiceover + sound effects directly (`--generate-audio`); the skill documents this path with explicit caveats — no ASR is available to verify spoken content, and cross-segment voice consistency across independent generations is not guaranteed.
- **Communicates in the user's language** for all Gate output/confirmations; only the imagegen/omni prompts sent to the models stay in English.
- Default project directory moved from `~/hyperframes-projects/` to the workspace's `outputs/` convention.

## Environment requirements

- `AI_GATEWAY_API_KEY` (usually already configured in Happycapy)
- Python >= 3.10, Node.js, ffmpeg/ffprobe
- Sibling `generate-image` and `generate-video` skills installed alongside this one

Run `scripts/check_setup.sh` on first use — it checks all of the above and tells you exactly what's missing.

## Usage

Say things like:

```
collage b-roll: most people think AI is here to think for you — really it's more like a mirror that shows you the holes in your own question.
```

or give it a full multi-line ad script and let Gate 0 propose a segmentation and duration plan.

Trigger phrases: `collage b-roll`, `paper collage b-roll`, `halftone collage`, `gbro-collage-broll`.

## Workflow

0. **Segment & duration plan** — auto-split the script, estimate per-segment seconds, confirm background-color mode, captions, and logo requirements
1. **Metaphor (Gate 1)** — one sharp visual metaphor per segment, text only, stop for confirmation
2. **Still frame (Gate 2)** — generate the final collage still per segment, stop for confirmation
3. **Video (Gate 3)** — Gemini Omni Flash assembles from an empty first frame to the confirmed still, with full QA (per-second contact sheet, first-frame check, end-frame comparison)

See `SKILL.md` for the full protocol, prompt templates, and QA checklists.
