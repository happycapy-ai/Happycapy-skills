# Seek and Analyze Video

This skill enables persistent video intelligence using Memories.ai. Install the full skill from the source repository for complete workflow guides and the Python API client.

## Setup

1. Get API key at https://memories.ai/app/service/key (free tier: 100 credits)
2. Set environment variable: export MEMORIES_API_KEY="your-key"
